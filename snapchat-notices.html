Open-source software

The Snapchat compatibility view is built from these Mercury Workshop packages:

  • @mercuryworkshop/scramjet 2.0.67-alpha.2
  • @mercuryworkshop/scramjet-controller 0.0.14
  • @mercuryworkshop/epoxy-transport 3.0.1 (includes epoxy-tls)

Licensed under AGPL-3.0. Sources and license: Scramjet, Epoxy transport. Exact source packages are available from the npm registry using the versions above. TR-os integration source is available in the project repository.

This view is not affiliated with Snapchat. Snapchat authentication, verification and account requirements remain managed by Snapchat.

The socket transport is built from @mercuryworkshop/libcurl-transport 2.0.5 (including libcurl.js). AGPL-3.0 source and license: CurlTransport and libcurl.js. The exact package is available from npm at the version above.

TR-os changes dated 2026-10-18: the Curl JavaScript validates and forwards the server-selected WebSocket subprotocol; the Scramjet WebSocket hook exposes it before the open event; controller injection no longer prints connection responses. The WASM binaries, TLS certificate validation, authentication and verification requirements are unchanged. Modified JavaScript source is served as snap-curl-transport.js, snap-engine.js and snap-controller.inject.js, and is available in the project repository above.

A pinned Snapchat a4b70008 public script receives two optional API guards when service-worker notifications are unavailable. The exact source hash and transformation are in snap-compat.js. This does not expose TR-os service-worker registration or change Snapchat authentication.
